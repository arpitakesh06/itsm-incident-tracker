# ITSM Incident Operations Tracker

A structured ITSM operations tracker replicating the full ITIL 4 
Incident → Problem → Change management chain, with integrated 
Known Error Database and SLA breach detection logic.

---

## Sheets

| Sheet | Description |
|-------|-------------|
| Incident Log | 45+ incidents logged across P1–P4 with MTTR and SLA breach detection |
| Problem Records | 5 problem records linked to recurring incidents |
| KEDB | 10 Known Error Database entries with workarounds |
| Change Requests | 5 change requests raised from resolved problem records |
| Dashboard | Summary metrics — MTTR, SLA compliance, incident volume by priority |

---

## Key Features

- Auto-calculated MTTR per incident
- SLA breach detection using conditional formulas
- Priority-based colour coding (P1 Red, P2 Orange, P3 Yellow)
- Full Incident → Problem → Change audit trail
- KEDB with workarounds for faster repeat incident resolution
- Management-ready dashboard with SLA compliance %
